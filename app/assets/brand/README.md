# tosk brand kit

Tosk, the red squirrel (Ratatosk), in the **storybook ink** style: tapered pen lines,
hatching, warm watercolour washes. Every piece exists in colour and in pure black/white
(`-mono`, for e-ink). Everything here is generated by `app/tool/brand/make_tosk.py`
(`python app/tool/brand/make_tosk.py all`); edit the generator, not the files.
`explore/` is the archive of the explorations (variant c of `explore/storybook/` is the chosen Tosk).

Preview of the whole kit: `docs/brand-sheet.png` (from `app/tool/brand/sheet.html`).

## What the app should bundle

Only the raster exports and the font are meant for the app bundle (the SVGs are sources;
they are polyline-heavy, 45-150 KB each, and the app has no SVG renderer):

| Bundle | Size | pubspec `assets:` entry |
| --- | --- | --- |
| `png/` (1x), `png/2.0x/`, `png/3.0x/` | 580 KB total | `assets/brand/png/` (Flutter picks the 2.0x/3.0x variants itself) |
| `fonts/Gelasio-Bold.ttf` (+ `OFL.txt`) | 108 KB | `fonts:` family `Gelasio`, weight 700 |
| `fonts/Gelasio[wght].ttf` | 169 KB, optional | variable weight 400-700 if regular-weight headings are wanted |

`icon/` (260 KB) is input for `flutter_launcher_icons` / `flutter_native_splash` only; it does
not go into `assets:`. Total added to the app: about 0.7 MB (0.86 MB with the variable font).

Each has a `-mono` twin (`png/tosk-celebrate-mono.png` ...) that is strictly black,
white and transparent (no grey pixels), so it is safe for the B/W pixel-scan tests. Colour
PNGs are 128-colour palette PNGs with alpha. Paths: `assets/brand/png/tosk-celebrate.png`,
`assets/brand/png/tosk-celebrate-mono.png`, and so on.

All poses face right and share the same canvas (512 figure space scaled down), bough at
the bottom, so they can be swapped in one slot. Light comes from the top right.

## Map pieces (the app paints these; SVGs are the reference)

- `node-states.svg` / `-mono`: locked, available, in progress, bronze, silver, gold in a row (r = 40).
- `node-<state>.svg` / `-mono`: one state each (140 x 140, node at the centre, r = 40).
- `twinkle.svg`: the four-point twinkle sprite.
- `branch-tile.svg` / `-mono`: a fork between three nodes (400 x 400) showing boughs, twigs, leaves.
- `leaf-a.svg`, `leaf-b.svg`, `leaf-c.svg` / `-mono`: ash leaf sprites (128 x 72): pinnate with three
  pairs; two pairs on a curved stem; a single leaflet.
- `yggdrasil.svg` / `-mono`: the whole tree (800 x 1100), optional decoration only.
- `branch-style.json`: the painter spec, see below.

### Sparkly tiers

| Tier | Rings | Sparkle |
| --- | --- | --- |
| bronze | 2 | one glint: a small twinkle at the top right |
| silver | 3 | two twinkles (top right, top left) and a dot |
| gold | 3 + 8 rays | four twinkles, three dots, rays; a paper-coloured gleam arc on the metal |

In motion mode the twinkles may breathe (opacity 0.6-1, scale 0.85-1.15, 1.6-2.4 s sine,
offset phases); with `reduceMotion` or in B/W they are static. Mono keeps the hierarchy by
ring count, rays and the twinkle outlines (white fill, black stroke).

## `branch-style.json`

All lengths are logical px unless stated as a fraction of `r` (node radius) or of the branch
length. Angles are degrees, 0 = right, positive = clockwise on screen.

- `palette`: the hex colours (ink, paper, fur, bark, leaf, gold, silver, bronze ...).
- `mono`: how B/W is derived (every fill -> white, every stroke -> black, hatch opacity 1).
- `light`: the light direction; ink outlines are heavy on the side facing away from it
  (`ink_outline`: width = min + (max - min) * max(0, -(n . light))^0.8, plus a slow +-18% noise).
- `bough`: widths for main boughs (40 -> 12), twigs (10 -> 4) and the trunk segment (42 -> 32);
  linear taper times 1-2 Gaussian knuckle bumps (amplitude 0.18-0.38, sigma 0.05-0.09 of the
  length, a crease stroke across each bump); bark fill; `grain` (3 dashed lines on the shadow
  side at -0.18/-0.35/-0.52 of the half width, dash 0.12-0.32 and gap 0.08-0.28 of the
  length, 1.5 px at 0.85 opacity); `hatch` on the shadow half (angle = direction + 70, spacing 6,
  1 px, opacity 0.62); `twigs` density and angles.
- `leaves`: the leaflet path (`LEAFLET`, 36 units long), fills, outline widths, hatch, the pinnate
  layout (stem path, pair positions 22/46/70, tip at 92, pair angle -57..-47) and placement rules.
- `nodes`: radii, base fills, ring counts and widths, the shadow crescent hatch, per-state hatch,
  the gleam arc, the progress ring (track radius 1.24 r, dashed 0.08/0.16 r; filled arc 0.16 r in
  leaf_dk with an ink cap dot), the "available" sprout leaflet, `sparkle` per tier (twinkles as
  angle / dist / size / rotate in units of r, dots, rays), the twinkle path for r = 1, and
  `extent` (1.75 r: how far sparkles reach beyond the node, for hit testing and overflow).

## Regenerating

```
python app/tool/brand/make_tosk.py          # SVGs, branch-style.json, sheet.html (1 s)
python app/tool/brand/make_tosk.py png      # + PNG exports via headless Edge + Pillow (~1 min)
python app/tool/brand/make_tosk.py sheet    # + docs/brand-sheet.png
python app/tool/brand/make_tosk.py all
```

Needs Python 3.10+, fontTools (wordmark), Pillow and Microsoft Edge (PNG exports); no other
dependencies. The generator is deterministic (seeded noise), so regenerating gives identical files.
